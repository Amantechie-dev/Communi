# Communi - Smart Volunteer Platform 

Communi    is a centralized,  easy-to -use web application designed to connect eager volunteers with   local community needs while verifying their impact  hours.

##  Tech Stack
* **Backend:** Python,   Flask
* **Database:** SQLite,   SQLAlchemy
* **Frontend:** HTML5,   CSS3, Jinja2

## Hackathon Evaluation Details

* **Innovation & Creativity:** Communi  modernizes the   outdated, fragmented volunteer ecosystem by bringing local opportunities into a single, centralized digital feed rather than scattered social media groups.
* **Technical Implementation:** Built with  a lightweight  Python/Flask backend and SQLite  database to ensure fast routing, secure user sessions, and rapid deployment.
* **Functionality:** The MVP features a  complete core loop: secure authentication,  frictionless event  creation for organizers, a real-time  discovery feed, and automated impact tracking.
* **Impact:** By replacing lost paper sign-in sheets with a  verifiable digital dashboard,  we provide students and professionals with official proof of their community service,  incentivizing long-term  civic engagement.
